## 个人博客主机的四条路线：先选类型，再看配置

## 免费方案能撑多久？

免费方案可以一直用，但有三个绕不开的限制：国内访问速度看运气，动态功能要靠第三方，平台型免费版的内容自主权有限。

GitHub Pages 是免费路线里最主流的选择：无广告，支持绑定自定义域名，配 Hexo、Hugo 或 Jekyll，用 Markdown 写完一推就发布。B 站上从零开始的 Hexo 搭建教程一搜一大把，跟着做一个下午能上线。它的短板也明确：纯静态，评论、搜索这类动态功能得接第三方服务；服务器在海外，国内访问速度随运营商和时段波动，所以常见做法是在外面再套一层 Cloudflare。

平台型服务是另一条免费路。WordPress.com 的免费版有广告且去不掉，域名只能用子域名；Medium 写作体验和内置流量都不错，但内容托管在平台手里，自定义空间很小，哪天平台调整规则，你只能接受。Blogger 相对干净，支持自定义域名，但功能扩展有限。

学生身份值得单独提一句：阿里云有面向学生的免费云服务器（一年），腾讯云轻量应用服务器也有过免费三个月的活动，符合条件先把这个用上，比什么都实在。

如果你的目标只是“有个地方写字”，免费方案就是终点；想要独立域名和完整的数据自主权，免费的尽头就是自己的主机。

## 国内云服务器还是海外 VPS：备案和续费才是真正的差价

两者的性能价格差已经不大，真正的分水岭在备案和续费政策：国内节点建站必须 ICP 备案，海外 VPS 完全免备案；国内活动价第二年常常跳涨，海外年付特价大多按循环价续费。

国内大厂这两年把轻量服务器的活动价卷得很低：阿里云、腾讯云都有 38 元一年的秒杀档，华为云 36 元起，百度云 59 元起。跑个人博客，2核2G3M 的入门配置就够。要留心的是续费：不少低价档是拉新价，第二年续费翻几倍，而你的域名备案恰恰挂在这家服务商名下，迁走麻烦，留下肉疼。阿里云有个 99 元一年的档位，续费同价，属于少数把续费价直接写明白的。

### 免备案的博客，域名要怎么解析？

在域名的 DNS 管理里加一条 A 记录，指向 VPS 的 IPv4 地址即可。国内注册商的解析服务照样能用，解析本身和备案无关，生效通常几分钟到几小时。

### 1GB 套餐装 WordPress 会卡吗？

装得动，但建议加 1–2GB swap、装缓存或静态化插件、控制插件数量。打算长期养博客的话，2GB 档的余量更省心。

### IP 被墙或者线路不理想怎么办？

先利用 30 天退款期测速，不满意直接申请退款。之后遇到 IP 问题可以提交工单咨询，能否更换、是否收费以官方答复为准。

### 静态博客还需要买 VPS 吗？

不需要。Hexo、Hugo 这类静态站放 GitHub Pages 或 Cloudflare Pages 就够，成本为零；VPS 的价值在跑 WordPress、Typecho 这类动态程序，以及一台机器顺便干别的活。
